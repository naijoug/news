# 响应式设计测试清单

## 测试环境
- Frontend: http://localhost:5173/
- Backend: http://localhost:3000/

## 桌面端测试 (> 1024px)

### ✓ 已实现的功能
1. **时间线最大宽度 800px 并居中**
   - CSS类: `.timeline-container` 在 `@media (min-width: 1024px)` 中设置 `max-width: 800px`
   - 时间线内容在大屏幕上居中显示

2. **优化新闻卡片布局和间距**
   - NewsCard 组件在桌面端使用 `lg:p-5` 增加内边距
   - 卡片间距通过 Timeline 的 `space-y-6` 控制

3. **实现固定顶部筛选器**
   - CSS类: `.platform-filter-sticky` 使用 `position: sticky` 和 `top: 73px`
   - 筛选器在滚动时保持在视口顶部

### 测试步骤
1. 在浏览器中打开 http://localhost:5173/
2. 将浏览器窗口调整到 > 1024px 宽度
3. 验证时间线是否居中且最大宽度为 800px
4. 滚动页面，验证筛选器是否固定在顶部
5. 检查新闻卡片的间距和布局是否合理

## 平板端测试 (768px - 1024px)

### ✓ 已实现的功能
1. **添加 768px-1024px 断点的媒体查询**
   - 在 `index.css` 中添加了平板端专用样式

2. **调整时间线宽度和字体大小**
   - 时间线宽度自适应容器
   - 平台名称字体大小调整为 `md:text-xs lg:text-sm`

3. **实现可折叠的筛选器**
   - PlatformFilter 组件添加了折叠/展开按钮
   - 使用 `isCollapsed` 状态控制显示
   - 折叠按钮仅在平板端显示 (`md:inline-flex lg:hidden`)

### 测试步骤
1. 将浏览器窗口调整到 768px - 1024px 宽度
2. 验证筛选器右侧是否显示折叠/展开按钮
3. 点击按钮，验证筛选器是否能正常折叠和展开
4. 检查时间线宽度是否自适应
5. 验证字体大小是否适中

## 移动端测试 (< 768px)

### ✓ 已实现的功能
1. **添加 < 768px 断点的媒体查询**
   - 在 `index.css` 中添加了移动端专用样式

2. **将筛选器改为底部抽屉式**
   - 在 App 组件中实现了底部抽屉 (`.platform-drawer`)
   - 添加了遮罩层 (`.platform-drawer-overlay`)
   - 头部添加了"筛选"按钮，显示已选平台数量
   - 抽屉可通过点击遮罩层或关闭按钮关闭

3. **简化时间线连接线样式**
   - 使用 `.timeline-line-mobile` 调整连接线位置 (`left: 1rem`)
   - 使用 `.timeline-dot-mobile` 缩小圆点尺寸 (0.5rem)
   - 使用 `.timeline-item-mobile` 减少左侧内边距 (2.5rem)

4. **增大触摸区域（最小 44px）**
   - 所有交互元素添加了 `.touch-target` 类
   - CSS 确保最小触摸区域为 44px x 44px

5. **优化移动端滚动性能**
   - 添加了 `-webkit-overflow-scrolling: touch` 优化 iOS 滚动
   - 使用 `scroll-behavior: smooth` 实现平滑滚动

### 测试步骤
1. 将浏览器窗口调整到 < 768px 宽度（或使用开发者工具的设备模拟）
2. 验证顶部筛选器是否隐藏，显示"筛选"按钮
3. 点击"筛选"按钮，验证底部抽屉是否从底部滑出
4. 验证抽屉背景遮罩是否显示
5. 点击遮罩或关闭按钮，验证抽屉是否关闭
6. 检查时间线连接线和圆点是否简化
7. 验证所有按钮和链接的触摸区域是否足够大
8. 测试滚动是否流畅
